# homebrew-computer

An 8-bit computer designed from scratch in Logisim Evolution around 7400-series TTL chips, together with the complete software stack that targets it. A hand-written compiler takes a subset of C to a stack-based virtual machine language, a translator lowers that to assembly, and a two-pass assembler produces machine code. Control logic is microcode: two Python scripts generate 32768-entry lookup tables for AT28C256 EEPROMs. The same binaries run in a headless JavaScript emulator with a gate-level 74181 model, in a React debugger app, and in the Logisim design. Three modules of the machine exist as physical PCBs.

![The emulator running a compiled C program](docs/media/emulator-run.gif)

## Facts

- 8-bit data path, 16-bit addressing, one bus
- Two 16-bit instruction formats, move and compute, with a free conditional jump in every compute
- ALU built from two chained 74181 slices with a fixed table of ten expressions
- Microcoded control: 2^15-entry tables generated by Python, burned to AT28C256 EEPROMs
- Memory map with 1KB ROM, 4KB dual-port VRAM (IDT7134), 32KB RAM, and two IO ports
- C compiler (lexer, recursive-descent parser, code generator) with pointers, arrays, recursion, and a full precedence ladder
- Stack-based VM with a calling convention that makes recursion work
- Two-pass assembler with symbols and an #origin directive
- Two emulators sharing one core: headless for tests, React app with disassembly, breakpoints, a live stack view, and about 12MHz uncapped
- 24-program test suite, each C file stored with its expected binary
- Clock, counter, and display modules built as physical PCBs
